⚙ GitHub Storage

Newsletters are stored as JSON files in a GitHub repo — this gives you free version history, backups, and keeps everything next to the builder. Reading from a public repo needs no token; saving requires a fine-grained token with Contents: Read & write on this repo.
Kept in this browser's local storage on this device only. Create one at github.com → Settings → Developer settings → Fine-grained tokens, scoped to just this repo with Contents read & write. Leave blank to browse a public repo read-only.
